## ビット判定

- `$X` の `$d` 番目のビットが0か1か**を判定

```
$X / (1 << $d)) % 2
```
または
```
($X >> $d) & 1
```

例 (ビットが1の位置を取得):
```php
<?php
$x = 21; // 0b10101
$array = [];
for ($d = 5; $d >= 0; $d--) {
    if (($x >> $d) & 1) $array[] = $d;
}
var_dump($array);
// array(3) {
//   [0]=>
//   int(4)
//   [1]=>
//   int(2)
//   [2]=>
//   int(0)
// }
```
